## ?? Feature 2: Activity Heatmap

The activity heatmap shows signal intensity across the entire timeline using color:
- **Blue**: Low/no activity (silence)

## ?? Tips & Tricks

### Marker Tips
1. **Use descriptive labels** - Edit marker labels to be meaningful
2. **Color-code markers** - Use different colors for different event types
3. **Export markers** - Save marker positions for reports
4. **Limit markers** - Too many markers clutters the view (~10-20 max)

### Heatmap Tips
1. **Toggle on/off** - Use heatmap for overview, disable for detail
2. **Combine with zoom** - Heatmap + zoomed waveform = best detail
3. **Multi-frequency** - Heatmap shows combined activity from all frequencies

### History Tips
1. **Use liberally** - Don't worry about "wrong" zooms, just go back
2. **Clear on new file** - Start fresh with each recording
3. **Combine with markers** - Mark important views before exploring

## ? FAQ

**Q: How many markers can I add?**  
A: Recommended maximum is 100 markers. Performance degrades beyond this.

**Q: Are markers saved with the file?**  
A: No, markers are session-only. You need to implement persistence yourself.

**Q: Can I change heatmap colors?**  
A: Currently no UI for this. You can modify the `GetHeatmapColor()` method.

**Q: Does history persist between sessions?**  
A: No, history is cleared when you load a new file or restart the application.

**Q: Can I edit marker labels after creation?**  
A: Not currently. This will be added in Phase 3.
