# Waveform MiniMap - Visual User Guide

## What is the MiniMap?

The MiniMap is a compact overview display located below the main waveform that shows:
- **The entire audio recording** at a glance
- **Your current viewing position** (highlighted blue region)
- **The playback position** (red line)

```
?????????????????????????????????????????????????????????????????
```

## Visual Elements

### 1. Waveform Overview
- Shows the **complete audio file** compressed to fit the minimap width
- Uses the same colors as the main waveform
- **Multi-frequency**: Each frequency displays in its assigned color

### 2. Viewport Indicator (Blue Highlight)
- The **highlighted blue rectangle** shows which part is visible in the main waveform
- **Size** indicates your zoom level:
  - Large rectangle = zoomed out (more visible)
  - Small rectangle = zoomed in (less visible)
  - No rectangle = full view (not zoomed)

### 3. Playhead (Red Line)
- Shows the **current playback position** across the entire timeline
- Moves smoothly during playback
- Visible even when zoomed in to sections where it's not showing in main view

### 4. Ending Time Display (Bottom-Right)
- Shows the **total recording duration** in `mm:ss.fff` format
- Always visible at the bottom-right corner
- Updates automatically when a file is loaded
- Example: `01:35.420` (1 minute, 35 seconds, 420 milliseconds)

## Tips and Tricks

### ?? Quick Navigation
- **Click on spikes** in the minimap to jump directly to active transmissions
- **Drag viewport** for smooth, controlled panning

### ?? Understanding Zoom Level
- **Wide viewport** = you can see a lot (good for overview)
- **Narrow viewport** = you're focused on a small region (good for detail)

### ?? Using with Playback
- **Watch the red playhead** move across the minimap during playback
- **See your position** relative to the entire recording
- **Jump ahead** by clicking where you want to play next
- **Check the ending time** (bottom-right) to see total recording duration

### ?? Finding Specific Events
- **Look for color changes** (different frequencies)
- **Look for amplitude spikes** (loud transmissions)
- **Look for gaps** (periods of silence)

## Keyboard + MiniMap Workflow

While the minimap doesn't have keyboard shortcuts yet, combine it with existing controls:

1. **Use Ctrl+Drag on main waveform** to zoom to a specific region
2. **Use minimap** to see where that region is in the full timeline
3. **Click minimap** to quickly navigate elsewhere
4. **Use zoom buttons** to adjust detail level
5. **Drag minimap viewport** for fine positioning

## Common Patterns

### Pattern 1: "Zoom and Explore"
```
1. Load file ? See full overview in minimap
2. Click on interesting region
3. Zoom in further with buttons
4. Use minimap to jump to next region
5. Repeat
```

### Pattern 2: "Detailed Scan"
```
1. Zoom in to desired detail level
2. Start at beginning (viewport on left)
3. Drag viewport slowly across minimap
4. Watch main waveform update
5. Stop when you find what you're looking for
```

### Pattern 3: "Playback Follow"
```
1. Start playback
2. Watch red line move across minimap
3. See upcoming activity in minimap
4. Jump ahead by clicking before playhead
5. Continue listening from new position
```

## Troubleshooting

### "I don't see the blue viewport"
? You're at full view (not zoomed in). Use the zoom buttons first.

### "The viewport won't drag past the edge"
? This is intentional - it prevents showing invalid regions.

### "I clicked but nothing happened"
? Make sure you have a file loaded and waveform data displayed.

### "The minimap looks different from the main view"
? The minimap is compressed - it shows the entire file in miniature.

## Summary

The MiniMap is your **navigation companion** for zoomed waveform viewing:

? **Orientation**: Always know where you are  
? **Navigation**: Click to jump, drag to pan  
? **Awareness**: See the entire recording at once  
? **Duration**: Total length displayed at bottom-right  
? **Efficiency**: Quick access to any part of the audio  

**Remember**: The minimap is always showing the **full recording**, while the main waveform shows **your current zoom level**.

---
**Pro Tip**: When deeply zoomed in (10x or more), the minimap becomes essential for not getting lost in the waveform! The ending time display helps you understand how far through the recording you are.
